# 发布文案模板（复制到项目 out/发布文案.md 再填）

> 视频号 / 抖音通用。发布前对照最后一节的自检表。

## 封面

- `out/封面.png`（1080×1920，从成片抽的钩子镜头）
- 平台若要别的比例：`python make_cover.py --ratios 6:7 --offset 0.22`，**裁完必须看一眼有没有把字幕切半**

## 一、短标题（列表页展示，≤16 字）

> **字符白名单（平台规则，不是审美）：** 符号只认 **书名号《》 / 引号“”‘’ / 冒号： / 加号+ /
> 问号？ / 百分号% / 摄氏度℃**；逗号一律换成空格。
> `@ # 顿号、分号、感叹号、括号、破折号、斜杠、小数点` 都会被判“含特殊字符”，标题直接发不出去。
> 写完跑 `python check_title.py --file out/发布文案.md`，PASS 再发布。

| 用途 | 标题 | 字数 | 为什么 |
|---|---|---|---|
| 主推 | `示例 四成代码不是人写的` | 12 | 格式示例：数字 + 反差（替换成这条片子的标题） |
| 备选 1 | `示例 AI同事最狠的设计：少说话` | 16 | 格式示例：主题句，冒号可用 |
| 备选 2 | `示例 群里的AI会自己找Bug` | 15 | 格式示例：用空格代替逗号 |

> 上表三行是格式示例，发布前必须换成本条视频的真实标题。

## 二、描述（主推版本）

```
第一行：钩子数字（不点“展开”就能看到的那 40 字）
第二行：反直觉的那句（不是……而是……）
第三段：证据（2–3 个数字，带来源口径）
第四段：给谁什么结论 / 怎么用
第五段：一句开放式提问

#话题1 #话题2 #话题3 #话题4 #话题5
```

## 三、描述（备选版本：换人群切入口）

```
换一个开头的人群（家长 → HR / 投资者 → 从业者），
正文数字与结论保持一致，不要出现和主版本矛盾的口径。

#话题1 #话题2 #话题3 #话题4 #话题5
```

## 四、话题

- 大词（保曝光）：2 个
- 垂类（保精准）：2 个
- 人群（保共鸣）：1–2 个
- **总数 4–6 个**，多了稀释曝光，也像营销号。

## 五、置顶评论

```
把主题句写成一句可带走的话 + 一个二选一问题（不是“你怎么看”）。
```

## 六、发布前自检

- [ ] 短标题 ≤16 字，和封面/开头第一句的数字口径一致（别标题“四成”、封面“40%”混着来）。
- [ ] 短标题只含白名单符号（书名号/引号/冒号/加号/问号/百分号/摄氏度，逗号已换成空格），
      `python check_title.py --file out/发布文案.md` PASS；`@`、顿号、感叹号、括号、小数点都没用。
- [ ] 描述第一行就是钩子，不放“本期视频聊聊”“大家好”。
- [ ] 描述里的每个数字都能在片中听到，且和片中的说法一致。
- [ ] 话题 4–6 个，三类齐全。
- [ ] 封面用钩子镜头，不是 0–1 秒的标题卡；手机缩略图下大字可读。
- [ ] 置顶评论已准备好（发布后自己发并置顶）。
