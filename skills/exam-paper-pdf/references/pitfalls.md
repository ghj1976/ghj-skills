下面前 6 条是工程坑，后面是排版本与学科侧的坑。

## 一、PDF 与素材

### 1.1 扫描件没有文字层
`pdf` 里 `/Subtype /Image` 10 处、`/Font` 0 处 → 纯图片 PDF。
`pdftotext` 抽出来是空；机器上也没有 `pdftoppm`、`PIL`、`pip`。
可行路线：正则抠出 `DCTDecode` 的 JPEG 流，一页一张（`extract_scan_images.py`）。
Producer 是 QuarkPDFCore，图像字典长这样，顺序固定，正则好写：

```
<</BitsPerComponent 8/ColorSpace/DeviceRGB/Filter/DCTDecode/Height 3111/Length 823290/Subtype/Image/Type/XObject/Width 2180>>
```

页尺寸 2180×3111 ≈ 264 dpi，整页缩到 1700px 宽仍然可读中文正文；
小字（上下标、化学式）要放大 3–6 倍。

### 1.2 没有 pip / PIL / imagemagick
`python3 -m pip` 直接报 `No module named pip`；`convert`、`magick`、`ffmpeg` 都没有。
改用 WSL 里的 Node + npm 包：

| 需求 | 包 |
|---|---|
| 读 JPEG / 裁切 / 拼版 | `@napi-rs/canvas`（预编译二进制，不编译） |
| 读 JPEG（纯 JS，备用） | `jpeg-js` + `pngjs` |
| PDF 渲染成图 | `pdfjs-dist` + `@napi-rs/canvas` |
| 驱动 Chrome 打印 | `puppeteer-core`（不下载 Chromium） |

### 1.3 中文文档渲染交给 Windows Chrome
WSL 里 `fc-list :lang=zh` 是空的（没有中文字体）。
直接用 `/mnt/c/Program Files/Google/Chrome/Application/chrome.exe` 打印，
它带微软雅黑，PDF 里字体被正确子集嵌入（`MicrosoftYaHei`、`MicrosoftYaHei-Bold`）。

## 二、插图裁剪（最惨的一轮）

### 2.1 肉眼估框 = 必然切图
第一版 15 张图的框都是“看页面缩略图估的”，结果：

| 图 | 症状 |
|---|---|
| 第 2 题 NH₃ 模型 | 顶部球被切掉一半、底部混进下一行选项 |
| 第 10 题 四实验对照表 | **左边框整条丢失**，D 列文字被截 |
| 第 19 题 装置图 | a 装置的分液漏斗被切、e 的“酚酞溶液”被切 |
| 第 9 题 制硝酸流程 | 最右“浓 HNO₃”方框被切 |
| 第 17 题 电解池 | 顶部导线与电池符号被切 |
| 第 13、17 题 | 下沿带进下一行文字（“① 用 HO—…”） |

### 2.2 正确做法：墨迹包围盒
在**只框住这张图**的窗口里，扫描所有像素求 `minX/minY/maxX/maxY`（灰度 < 150 算墨迹），
再四周加 8–15px。`figcrop.mjs auto` 就是这个。

判断窗口好不好，看它报不报“贴边”：

- 报“贴边” = 墨迹触到窗口边缘 → 要么图被窗口截断（放大窗口），要么窗口里混进了邻行文字（收窗口/挪窗口）。
- 不贴边 = 窗口把图完整包住了，此时的 bbox 可信。

### 2.3 图和文字垂直重叠时，行投影才管用
第 2 题的模型紧贴下一行选项，水平方向还和选项文字重叠。
对整窗做“逐行墨迹计数”就能看出分界：

```
1630 10    ← 模型顶部球开始
...
1735 27    ← 模型最后一行
1740 0     ← 空白带
1775 0
1780 69    ← 下一行选项文字开始
```

结论：模型 y 范围 1630–1737，之后是空白，1780 起是文字。
同样手法用在第 17 题克劳斯流程（550–645 是图，680 起是文字），一次就切干净了。

### 2.4 小图不要放大
第 2 题模型在原卷上只有约 14mm 宽（142×128 px），这是它的真实尺寸。
按原始像素放进 A4（约 37mm 宽）已经是 2.7 倍放大，再撑到通栏只会更糊。
`figure img { max-width:100% }` 就够了，不要写 `width:100%`。

### 2.5 交付前必做两道检查
1. `figcrop.mjs check figs --min 3`：逐张报四边墨迹距离。
2. `figcrop.mjs sheet figs review.png`：把 15 张拼成一张长图，一屏看完。
   贴边报警不一定是切图（可能是带进文字），必须结合拼版图判断。

## 三、Markdown → HTML → PDF

### 3.1 `**加粗**` 跨行失效
原文里答案写成三行化学方程式、包在一对 `**…**` 里。
`/\*\*(.+?)\*\*/` 的 `.` 不匹配换行 → 渲染成裸 `**`。改成 `/\*\*([\s\S]+?)\*\*/`。
更好的是把多条方程式写成多条 `- ` 列表，从源头避免。

### 3.2 列表行被段落吞掉
段落收集循环没把 `- ` 当终止符，结果 `- Ag + …` 原样输出成一行文字。
段落终止条件要包含 `!` 看图行、`-` 列表行、`>` 引用行、`|` 表格行。

### 3.3 图片相对路径
md 在项目根、print.html 在 `work/` 下，`figs/x.png` 会 404。
转换时按“输出 HTML 所在目录”重算相对路径（`path.relative`），一次性解决。

### 3.4 页脚：命令行打印没有页码
`chrome --print-to-pdf --no-pdf-header-footer` 出来是干净页面，但没有页码。
想加页码只能 CDP：

```js
page.pdf({ displayHeaderFooter:true, headerTemplate:'<div></div>',
  footerTemplate:'第 <span class="pageNumber"></span> 页 / 共 <span class="totalPages"></span> 页' })
```

### 3.5 `position:fixed` 假页脚会压正文
先在 CSS 里试了 `.footer{position:fixed;bottom:-7mm}`：单看 HTML 挺好，
CDP 打印后它被画到**页面顶部**、正好压在第 4 页正文第一行上。删掉，改用 CDP 页脚。

### 3.6 WSL 路径写成 Windows 路径
`makepdf.mjs` 传 `D:\test\yy\out.pdf`，Node 在 WSL 里跑，于是生成一个名叫
`work/D:\test\yy\out.pdf` 的文件（名字里带冒号和反斜杠）。一律传 `/mnt/d/...`。

### 3.7 页面尺寸
`chrome --print-to-pdf` 读了 `@page{size:A4}`，MediaBox 是 595×842，没问题。
但保险起见每次都用 `check_pdf.py` 看一眼——612×792 就是 Letter，页边距全乱。

### 3.8 图高与分页
`figure img{max-height:78mm}` 时，Q17 的三个图挤不下，整页底部空出 1/3。
压到 67mm 后三张图同页，总页数从 16 降到 15。
判断标准：**每页底部空白超过 1/4 就该调**。

### 3.9 末页只剩两行
15 页的最后一页当时只有“易错点提示”的标题和 6 条，
后面 3/4 是空白。接受它（册子类文档正常），或者整体压 0.2pt 字号把它并进前一页。

## 四、内容侧（学科）易错点

这些不是排版问题，但每一条都在本次出现过，写解析时值得逐个核对：

1. **VSEPR 模型 ≠ 空间结构。** NH₃ 的 VSEPR 模型是四面体形，空间结构才是三角锥形。
2. **“性质—用途”题看因果。** CaSO₄→CaCO₃ 靠的是 CaCO₃ 的 Ksp 更小，不是“Na₂CO₃ 显碱性”。
3. **吸氧腐蚀的电极式别写错。** 负极 Fe−2e⁻=Fe²⁺，正极 O₂+2H₂O+4e⁻=4OH⁻；写成 Fe³⁺/H⁺ 就是错项。
4. **增大反应物浓度 → 另一反应物的平衡浓度必减小。** “大于 c₀(1−x₂/100)”这种选项是典型陷阱。
5. **晶胞粒子数。** Li 体心立方=2；LiH 类 NaCl=4（4 个“LiH”）。算密度比前先数清楚。
6. **Ksp 与两次除杂。** PbCl₂(1.7×10⁻⁵) 远大于 AgCl(1.8×10⁻¹⁰)：沉银时铅留在溶液里，才谈得上“两次除铅”。
7. **原电池/电解池先判电极。** 图上电源长短线、电子流向、O₂ 在阴极得电子——判错电极整题崩。
8. **电子守恒配平。** H₂S→SO₃²⁻ 失 6e⁻，O₂ 经 HO₂⁻ 每分子得 2e⁻，要 3 个 HO₂⁻；由此还能顺势解释“为什么 HCHO 过量”（每 1 mol SO₃²⁻ 伴生 3 mol HCHO，成 HMS 只耗 1 mol）。
9. **“少量氯水使淀粉-KI 变蓝”不能证明反应有限度。** Cl₂ 和 HClO 都能氧化 I⁻，结论不唯一。
10. **有机/结构小问的“单质 vs 化合物”。** 机理图里 X 是 I₂ 或 Br₂（单质），说“两种不同的化合物”就是错的。

## 五、流程上的教训

1. **先问清交付形态**（要 PDF 还是只要文字、要不要原题、要不要页码），再动手排。
   本次是“先出 6 页答案册 → 又要原题 → 又要 A4 带页码”，白返工两轮。
2. **先做 2 页样张**（1 道选择 + 1 道大题），确认版式、图、页脚都对了再批量排 15 页。
3. **图和文的相对位置要一眼能对上。** 图被挤到下一页时，图注里要写“第 X 题……”，
   否则读者翻页后不知道这是哪道题的图。
4. **交付时点名不确定项。** 扫描件识读一定有 1–2 处拿不准（箭头方向、导管长短），
   在回复里列出来让用户对原卷核，比假装确定更省事。
