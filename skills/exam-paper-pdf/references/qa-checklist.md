# 交付前检查清单

按顺序过一遍，每项都要有明确结论（不是“应该没问题”）。

## 一、原题完整性

- [ ] 每道题的题干、四个选项（或每个小问）、空格、已知条件表都已转写，无漏项。
- [ ] 原卷有图的题，**图也贴了**；图注写明“第 X 题……”。
- [ ] 图上的文字与正文不矛盾（例如选项 B 写“模型如图”，正文就不要把图删掉）。
- [ ] 分值、题号、总分对得上（14×3=42 + 58 = 100）。
- [ ] 原卷的表格（Ksp 表、实验对照表）要么转成 Markdown 表，要么整张截图，二者择一且完整。

## 二、插图（逐张）

- [ ] `node scripts/figcrop.mjs check figs --min 3` 无“贴边”告警，或有告警但已确认是文字混入而非切图。
- [ ] `node scripts/figcrop.mjs sheet figs review.png` 拼版图逐张看过：四边有余量、没有被切掉的笔画/边框/文字。
- [ ] 表格类截图包含**所有边框**（左、右、上、下）。
- [ ] 流程图/装置图包含所有子部件（电源符号、导线、尾气处理、装置标签 a–e）。
- [ ] 坐标图包含坐标轴标题、刻度、图例、图注（“图 1”“图 2”）。
- [ ] 小图没有被硬放大到模糊；大图没有被压缩到看不清。

## 三、答案与解析

- [ ] 选择题每题只有一个明确答案，且写明了另外三项为什么对/错。
- [ ] 填空题的答案单位、有效数字、正负号、上下标齐全（mol·L⁻¹、×10⁻¹⁰、ΔH>0）。
- [ ] 化学方程式配平，条件（Δ、催化剂、电解）标注，↑↓ 标注。
- [ ] 计算题给出算式和代入过程，不只给结果。
- [ ] “不正确/不合理/不能”等否定词被高亮或加粗，避免读者看反。
- [ ] 卷首有答案速查表，卷末有易错点/复盘。
- [ ] 不确定的 1–2 处在交付说明里点名。

## 四、版面

- [ ] `md2page.mjs` 生成的 HTML 无裸 `**`、无裸 `- `、无 404 图。
- [ ] 题目框（`>`）不被拆到两页只剩半行。
- [ ] 图不把“答案”和“解析”劈开（图紧跟在题目后、答案前）。
- [ ] 表格不跨页断行（`break-inside:avoid`）。
- [ ] 每页底部空白 < 1/4；末页不是只剩两三行。
- [ ] 标题不孤行（`h2/h3 break-after:avoid`）。

## 五、PDF

- [ ] `python3 scripts/check_pdf.py 答案.pdf --expect A4` 通过：595×842pt、字体已子集嵌入。
- [ ] `node scripts/render_pages.mjs 答案.pdf work/pages` 逐页渲染后看过至少 4 页（首页、含大表的页、含三张图的页、末页）。
- [ ] 页脚页码正确：“第 X 页 / 共 Y 页”，总数与实际页数一致。
- [ ] 没有内容被页脚/页边距裁掉（看每页最底下一行）。
- [ ] 黑白打印仍然可读（加粗和浅底色不要只靠颜色区分）。

## 六、交付

- [ ] 同时给出 `.md`、`.html`、`_A4.pdf` 三份，文件名带卷别与内容。
- [ ] 回复里给打印建议：A4 纵向、100% 比例、双面。
- [ ] 说明 `figs/`、`work/` 是过程目录，可删。
